# Testing

## Coverage tooling (reference)

| Artefact                                 | Role                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ---------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `packages/config/vitest-coverage.mts`    | shared v8 include/exclude + thresholds; a partitioned App ([ADR-0023](../architecture/adr/0023-ci-coverage-partitions.md)) must keep exactly the four global floors, which its CI parts defer and its merge applies to the full map; glob-pattern or object-form `perFile` floors make its parts fail closed; its merge reads `coverage/<App directory>/coverage-summary.json`, so the App must call `makeCoverage` with its directory name, as Kit Apps do, or the merge fails closed                                                                                                                                                                                                                                                                                                       |
| `scripts/kit/test-coverage.sh`           | monorepo runner behind root `bun run test:coverage`; runs native Vitest coverage for each workspace. Membership is discovered (`test:coverage` script); kit tiers live in the script, product tiers in `config/product/coverage-order.txt` (`<high\|medium\|lower> <workspace>`), and any undeclared, stale or duplicate workspace fails — see **CP-COVERAGE-ORDER**, which also bounds `COVERAGE_ONLY` and `COVERAGE_CHANGED_BASE`; neither mode executes the Root gate. CI partition declarations (Kit `COVERAGE_PARTITIONS`, Product `config/product/coverage-partitions.txt`: `apps/<name> <N>`, N in 2-4) fail in the same pass when invalid and never change local runs; see **CP-COVERAGE-PARTITION**. Turbo is **not** in this path — `turbo.jsonc` declares no `test:coverage` task |
| `<pkg>/package.json` → `test:coverage`   | equivalent per-package entry point for a single package; the monorepo runner bypasses it and invokes `vitest` directly                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `scripts/kit/print-coverage-summary.mjs` | table after run                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `coverage/<pkg>/index.html`              | HTML report (gitignored); for a partitioned App, CI uploads only the merge's report files, never a part's partial report                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |

Support directories at any depth, DOM setup files, the private auth repo SQLite fixture and the Node-only Worker alias are excluded from runtime coverage by the shared configuration. Coverage floors are unchanged; support execution must not inflate the production-code percentage.

**Interpretation:** low `example-web` / `ui` global % is **expected** while T0 and CP-\* hold. Raise ui/web % only by **adding contract/page tests that map to risk**, not by rendering every shadcn export.
